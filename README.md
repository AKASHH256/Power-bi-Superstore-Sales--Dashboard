# Superstore Sales Dashboard

## Project Overview
Interactive Power BI dashboard analyzing sales and profit performance across regions, categories, cities, states, and sub-categories.

## Key Insights
- Total Sales: 2.30M
- Total Profit: 286.24K
- Profit Margin: 12.47%
- West Region generated highest sales
- Technology category generated highest profit

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization
